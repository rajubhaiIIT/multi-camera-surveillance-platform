# Data, privacy and licensing notes

- Only public datasets and footage of people who gave consent are used.
- Face data is biometric personal data (India's DPDP Act 2023). Enrolled faces are stored only for the demo, with consent, and can be deleted.
- Record here, per dataset: name, source URL, license, date downloaded.
- Known model licenses: Ultralytics YOLO is AGPL-3.0; InsightFace pretrained weights are non-commercial.
